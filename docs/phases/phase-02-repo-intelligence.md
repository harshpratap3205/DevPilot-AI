# Phase 02 — Repository Intelligence

## Scope
- Ephemeral repository tarball fetching and memory extraction.
- Path traversal, zip bomb, and symlink protection guards.
- Language, framework, and package manager auto-detection (TypeScript, JavaScript, Python, Go, Java, Rust).
- AST parsing for Express, Next.js (App & Pages Router), and FastAPI routes.
- Confidence scoring for static vs dynamic route endpoints.
- Dependency graph extraction (module imports, external packages).
- Interactive architecture visualizer using React Flow in the web dashboard.
