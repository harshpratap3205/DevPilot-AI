# Phase 04 — Infrastructure Generator

## Scope
- Structured deployment specification schema (`DeploymentSpec`).
- Production-grade templates for multi-stage non-root Dockerfiles, Docker Compose, Kubernetes manifests, and Helm charts.
- LLM proposal engine for optimizing runtime arguments, cache layers, and environment bindings.
- Linting and policy validation gate (`dockerfile-lint`, `kubeval`, `helm lint`).
- Web preview diff view with human approval workflows.
- Committing approved configurations to repository branches via GitHub App.
